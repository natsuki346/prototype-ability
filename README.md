# Ability 3画面プロトタイプ

Now / Past / Report の画面イメージを確認するための軽量プロトタイプです。すべて架空のサンプルデータで、実機接続や状態推定は行いません。

## 起動方法

ビルドは不要です。リポジトリ直下で以下を実行し、ブラウザでURLを開いてください。

```bash
python3 -m http.server 4173
```

http://localhost:4173/index.html

## 今回できること

- Now：顔・短いメッセージ・3つの状態候補と仮スコアの表示、表示用のサンプル状態切替
- Past：時刻スライダー、選択時刻の5指標、指標ごとの簡易グラフ、変化履歴と記録シート
- Report：期間、変化・通知・記録件数、内訳、関連の例、未確認の変化
- 日本語／英語切替（選択言語はlocalStorageに保存）
- 記録の保存・再表示、「後で記録」「記録しない」、サンプルデータへの復元

記録本文は入力されたまま保存し、言語切替で翻訳しません。言語や記録はブラウザのlocalStorageに保存されます。

## 未実装の範囲

センサー接続・USB通信、状態推定・変化検知・個人化、実際の通知配信、認証・クラウドDB・外部API、音声入力は実装していません。表示値・候補・レポートはすべて表示確認用のサンプルです。
