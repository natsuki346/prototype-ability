# Ability 画面構成プロトタイプ

実機連携前に、`Just now` / `Past` / `傾向` の3画面と、変化への記録操作を確認するための軽量プロトタイプです。サンプルデータは `app.js` の表示用データとして分離しています。

## 起動方法

ビルドは不要です。`index.html` をブラウザで開いてください。

```bash
open index.html
```

## 今回できること

- 下部ナビゲーションで3画面を切り替え
- Just nowで5指標・仮基準との差・変化イベント・状態候補を表示
- イベントを「今記録する」「後で記録する」「記録しない」に変更
- Pastで履歴、前後の簡易グラフ、観察事実と感情の見立てを分けた記録シートを表示
- 記録をブラウザの `localStorage` に保存・再表示（片方／両方／未入力で保存可能）
- 「サンプルに戻す」で初期状態へ復元
- 傾向画面で件数と日別グラフ、断定を避けた関連の表示

## 未実装の範囲

センサー接続・USB通信、状態推定・変化検知・個人化モデル、実際の通知配信、認証・クラウドDB・外部API、音声入力は実装していません。表示される計測値・状態候補はすべてサンプルです。
